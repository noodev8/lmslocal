-- Every release (both stores)
1. Bump version in lmslocal-flutter/pubspec.yaml (x.y.z+build; build always goes up).
2. Build from a clean checkout of what is committed - anything changed in Xcode or Android Studio
   must be committed first. The repo is what ships (see docs/mobile-notifications.md section 5).
3. Test on a real phone: sign in, then check a new device_tokens row appeared for that account,
   then send a test push from admin Emails against production and tap it.
4. Minimum version (app_version table) only if old builds must be forced off. Not by default.

-- iOS

- Runner.entitlements must contain aps-environment. Do not remove it.
